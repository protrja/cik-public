Abonnement

Les abonnements CiK sont gérés par Apple. Vous pouvez consulter, modifier ou résilier votre abonnement depuis les réglages de votre compte Apple. Si un abonnement actif n’est pas reconnu dans CiK, utilisez également l’action « Restaurer les achats » dans l’application.

Vos données

Les données financières saisies dans CiK restent sur votre iPhone et dans la sauvegarde iCloud privée de votre compte Apple. Vous pouvez les supprimer depuis Réglages → Effacer mes données : les données de l'iPhone et leur sauvegarde iCloud sont supprimées ensemble. L'abonnement n'est pas résilié par ce geste.

La mesure d'usage n'a lieu qu'avec votre accord ; vous pouvez la couper d'un seul geste dans Réglages → Aide → Amélioration de l'application, et la politique de confidentialité décrit précisément ce qui est envoyé.

Pour une question sur vos données pseudonymes, joignez à votre message votre Identifiant d'assistance, affiché en bas des Réglages de CiK (appui long pour le copier).
